# bloom-ledger: first public release

Self-hosted earnings, power and tax ledger for Darkbloom Macs. Run the server with Docker or on a Mac, add each Mac with one command, finish setup in the browser. No cloud, no telemetry, no extra dependencies.

Upgrading from a private install: your settings are migrated automatically on first start and nothing else changes. Create an admin login at `/setup` when convenient; until then writes keep working from your local network as before.
