Machines

Each machine reports into the ledger with its own token. Edit the name, model, acquisition and lease, then save the row. Set Acquired first: a leased machine takes the lease start and monthly payment, a purchased one takes the in-service date and purchase price. Each row labels its own two fields.
Machine id Display name Model Acquired Start date Amount Last seen Days sealed Status Actions

A machine id cannot be renamed because its history is write-once and hash-chained. To use a new id, add a machine and remove the old one. Removing a machine revokes its token and hides it here; its history is kept.
